
# GradFit SA

GradFit SA is a lightweight web application designed to help South African IT students and recent graduates check whether they meet the requirements of internships, graduate programmes and entry-level IT opportunities.

## Project Status
Planning and system design completed. Implementation has not started.

## Planned Technology Stack
- C#
- ASP.NET Core MVC
- HTML, CSS and JavaScript
- Entity Framework Core
- SQLite

## Project Goal
Help graduates understand which job requirements they meet and identify eligibility gaps before applying.
